# Design direction

Composed with `scripts/design-direction.js --type cafe --name "Kiln & Bean"` and edited for the brief (a six-seat coffee bar with a pottery studio, no photography supplied).

| Axis | Choice | Reason |
|---|---|---|
| Theme | Terracotta | local café; clay and sand match a pottery studio literally |
| Hero | editorial | no photography supplied; the copy and the "open today" facts carry it |
| Navigation | inline | four section links and a mode toggle, nothing worth a button |
| Rhythm | bands | one page: hours and visit sit on a muted band so the menu and contact read as separate rooms |
| Cards | edged + soft shadow | menus read as printed cards on a counter |
| Buttons | soft | the theme's radius; pills would read as an app |
| Type | serif-display / regular | Fraunces headings feel hand-set; Nunito Sans keeps prices and the form plain |
| Imagery | none | nothing supplied; no stock photography |
| Motion | functional + reveal-once | sections below the fold; theme cross-fade |
| Density | regular | |

Alternatives offered: (B) Gallery · statement · minimal nav · bands · edged · sharp · all-sans/tight · photo-sharp; (C) Terracotta · editorial · centered nav · columns · bare · pill · all-sans/tight · illustration · airy.
